# Krisye Learning Centre (Krisye LMS)

Aplikasi e-learning untuk program pelatihan Krisye Learning Centre: membawa member Pantas Foundation dan anak perusahaannya dari Level 0 (Fondasi) sampai Level 10 (Managerial).

Peran: peserta (mahasiswa), trainer (dosen), dan pengelola (PJ program).
